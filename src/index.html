05 / SOB O SEU CONTROLO

Local. E transparente.

Os seus conteúdos ficam neste navegador. A cópia de segurança fica consigo.

Backup e exportação

O JSON inclui biblioteca, briefing e editor em curso. Guarde-o num local apropriado antes de limpar dados do browser.

Importar um backup

Apenas o formato Pauta v1, até 2 MB e 200 conteúdos. Importações são validadas e nunca executadas como código.

Privacidade e recuperação

  • Sem sincronização entre dispositivos, contas, APIs ou transmissão de conteúdo.
  • localStorage não é armazenamento seguro para informação sensível.
  • Modo privado, quota ou limpeza do browser podem impedir ou apagar a gravação.
  • Existe uma cópia local da gravação anterior. Não substitui um backup descarregado.
  • Use uma janela de edição de cada vez. Alterações concorrentes bloqueiam a gravação para evitar sobrescrita silenciosa.

Eliminar dados locais

Apaga biblioteca, briefing, editor e cópias de recuperação desta aplicação neste navegador. Não apaga ficheiros já descarregados.
